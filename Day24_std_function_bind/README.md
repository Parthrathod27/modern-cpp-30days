# Day 24 — std::function & std::bind (Modern C++)

## 📌 Topic
**Callable Abstractions & Callbacks**

This day focuses on handling different
callable types uniformly using `std::function`
and adapting functions with `std::bind`.

---

## 🎯 Learning Objectives
- Understand callable abstraction
- Learn type erasure
- Use std::function for callbacks
- Understand std::bind and placeholders

---

## 🧠 Key Concepts
- Type erasure
- Function signatures
- Partial function application
- Runtime flexibility

---

## 🚀 Why This Matters
- Event-driven design
- Plugin systems
- Decoupled architecture

---

## 💬 Interview Takeaways
- "std::function stores any callable"
- "Uses type erasure"
- "Prefer lambda over bind"
